Frequently Asked Questions

Common questions answered

Select a question to expand the answer.

How do I upload and edit a PDF in ZayroDocX?+

From your dashboard, select Upload and choose a file from your device. Once uploaded, open the document to access the editing tools. Each tool page shows accepted file types and any size limits upfront.

Do I need an account to use the tools?+

Some basic tools are available as a guest. For the full suite — AI tools, OCR, Invoice Extractor, and more — you'll need to create a free account. No credit card required to sign up.

Why did my OCR result come out inaccurate?+

OCR accuracy depends on scan quality, font clarity, and document language. Try re-scanning at a higher resolution (300 DPI or above) or straightening a skewed page. Avoid scans with heavy watermarks or overlapping text.

Can I merge files of different formats?+

The Merge PDF tool combines PDF files only. If you're starting with Word, Excel, or images, convert them to PDF first using the Convert PDF tool, then merge the resulting PDFs.

Is there a file size or page limit?+

Limits vary by tool and account type. The current limit is displayed directly on each tool page before you upload — so you'll know before you start. Larger files are supported on Pro accounts.

How do I reset my password or update my email?+

Go to your profile settings and look for the Security section to reset your password or update your email address. You'll need to confirm the change from your current inbox before the update takes effect.

What happens to my files if I cancel my plan?+

ZayroDocX does not retain uploaded files beyond the session — files are deleted immediately after processing regardless of plan. Cancelling your plan only affects which tools and usage limits are available to you going forward.

How do I report a bug or a failed export?+

Use the Contact Support form below, select Troubleshooting as the issue type, and attach a screenshot if possible. Include the tool name and any error message you saw — this speeds up diagnosis significantly.

The tool is stuck or showing an error — what should I do?+

First, try refreshing the page and re-uploading the file. If the error persists, check that the file type is supported and the size is within the tool's limit. Still stuck? Contact support with the error message and we'll look into it.
